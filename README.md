# Тестовое задание: Развертывание веб-приложения

Простое веб-приложение на Python, доступное через reverse-proxy, упакованное в Docker-контейнеры.

## Архитектура и схема взаимодействия

Взаимодействие происходит внутри изолированной docker-сети. Nginx принимает входящие HTTP-запросы на 80 порту хоста и проксирует их на Backend-сервис, который работает на 8080 порту.

## Использованные технологии
- Docker & Docker Compose
- Nginx (Alpine)
- Python 3.11 (http.server, Alpine)

## Как запустить проект

1. Убедитесь, что у вас установлены Docker и Docker Compose.
2. Склонируйте этот репозиторий и перейдите в его директорию.
3. Выполните команду для сборки и запуска контейнеров в фоновом режиме:
   ```bash
   docker-compose up -d --build
